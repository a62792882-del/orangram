# Orangram — запуск с iPhone

Это ранняя веб-версия: регистрация/вход, поиск по юзернейму и личные сообщения между разными устройствами. Для синхронизации нужен Supabase. ZIP нельзя просто загрузить как единственный файл и ожидать, что сайт запустится — сначала распакуй архив и загрузи `index.html` в корень репозитория.

## 1. Создай базу данных
1. Открой https://supabase.com/ и создай проект.
2. В проекте открой SQL Editor → New query.
3. Открой `schema.sql`, скопируй весь текст, вставь в SQL Editor и нажми Run.
4. В Project Settings → API скопируй Project URL и `anon`/publishable public key. Никому не отправляй `service_role` key.

## 2. Подключи сайт
1. Открой `index.html` в редакторе текста.
2. Найди `ВСТАВЬ_PROJECT_URL` и `ВСТАВЬ_ANON_PUBLIC_KEY`, замени их своими значениями.
3. Сохрани файл.

## 3. Опубликуй на GitHub Pages
1. Загрузи `index.html` в корень репозитория `orangram` (можно заменить README не нужно).
2. В GitHub открой Settings → Pages.
3. В Build and deployment выбери Deploy from a branch, branch `main`, folder `/ (root)`, Save.
4. Подожди публикации; адрес будет вида `https://ТВОЙ-ЛОГИН.github.io/orangram/`.

## Важно
- На регистрации может потребоваться подтверждение почты.
- В Supabase Authentication → URL Configuration добавь опубликованный GitHub Pages URL в Site URL и Redirect URLs.
- Это ранний прототип, не полноценная защищённая платформа. Не используй для секретной переписки.
- Админ-панель и безопасная выдача апельсинов пока не включены. Не добавляй админ-права только через JavaScript: это небезопасно. Следующим этапом их надо сделать серверной функцией с проверкой роли.
